# 공개 주차장 기준 자료

`parking.json.gz`는 전국주차장정보표준데이터 API에서 전체 수집한 공개 자료입니다. 2026-10-28 수집 당시 원본 18,939건에서 좌표 미제공 766건과 중복을 정리한 17,059곳이 포함됩니다. API 인증키·환경변수·요청 URL은 포함하지 않습니다. 개별 항목의 데이터 기준일은 `referenceDate`로 보존됩니다.

출처: https://www.data.go.kr/data/15012896/standard.do

Vercel에서 초기 추천을 제공하기 위한 기준 자료이며, 최신 자료 수집에 성공하면 교체 사용합니다. 24시간 이상 지난 자료는 이전 데이터라는 안내가 표시됩니다. `.cache/`의 로컬 실행 기록은 Git에 포함하지 않습니다.
